Forest Plots How to Read Them

An educational guide to forest Plots How to Read Them, focused on research literacy rather than hype.

2026-10-10 12 min read Intro Students

Key takeaways

  • Forest plots display effect estimates and confidence intervals across subgroups or studies—horizontal line at null (HR=1 or RR=1) is reference.
  • Square size reflects weight in meta-analysis; diamond summarizes pooled effect—check heterogeneity I² and τ².
  • Subgroup lines are exploratory unless interaction p-values prespecified and trial powered for interaction.
  • Relative measures dominate forest plots—seek absolute event data in tables accompanying figures.
  • Overlapping confidence intervals suggest no strong subgroup modification—not proof of uniformity.

What problem the research is trying to solve

Meta-analyses and trial subgroup reports use forest plots as visual grammar for uncertainty.

Misreading plots causes overconfidence in ‘benefit only in men’ narratives from chance splits.

Students learn systematic reading order: pooled estimate, heterogeneity, then subgroups.

Educational—not a substitute for reading full methods.

How studies in this area are usually designed

Fixed-effect models assume one true effect; random-effects models account for between-study variation—cardiology meta-analyses often random-effects.

Trial-level forest plots in supplementary appendices show primary endpoint subgroups (age, sex, diabetes).

Leave-one-out sensitivity analyses test influential studies.

Publication bias funnel plots sometimes accompany forests—egger test limitations acknowledged.

How to read claims critically

If subgroup diamond excludes null but overall does not, suspect multiplicity—count how many subgroups tested.

Relative HR 0.8 in low-risk subgroup with wide CI overlaps 1.0—headlines omit width.

Absolute risk forest plots rare—construct mentally from event tables when possible.

Different scales (OR vs HR) should not be pooled naively—check model.

What is ready for clinics versus still emerging

Guideline panels use meta-analytic forests in evidence reviews—GRADE certainty considers heterogeneity.

Clinic-ready skill for interpreting society documents and journal club slides.

AI-generated forest plots in preprints require same scrutiny as published.

Interactive plots online should show underlying numbers on hover—transparency marker.

Student takeaways and further reading habits

Practice with Cochrane review forest for statins in secondary prevention.

Read ACC guideline supplemental meta-analysis figures.

PubMed ‘forest plot tutorial cardiovascular’.

Draw null line and label axes before interpreting subgroups.

Putting it together

Forest plots compress trials into one image—powerful if read with heterogeneity and multiplicity discipline.

Pair every forest with absolute event context when deciding relevance.

Cardily builds visual statistical literacy.
